# RIval Tickets

Discord-бот заявок на Python (`discord.py`) с приватными ветками, SQLite-хранилищем, оценкой поддержки и журналом действий.

## Запуск в Windows

1. Установи Python 3.10 или новее с [python.org](https://www.python.org/downloads/). При установке включи `Add Python to PATH`.
2. В Discord Developer Portal создай Application, открой вкладку **Bot** и создай/скопируй токен. Никому его не отправляй.
3. В **OAuth2 → URL Generator** выбери scopes `bot` и `applications.commands`. В **Bot Permissions** выбери `Administrator`, открой сгенерированную ссылку и добавь бота на сервер. Это даст боту полный доступ к каналам и настройкам сервера.
4. Включи Developer Mode в Discord, скопируй ID сервера. Значения ролей и канала логов заданы по умолчанию, но их можно выбрать через `/setup`.
5. Запусти `setup.bat`. Он создаст виртуальное окружение и установит зависимости.
6. Скопируй `.env.example` в `.env` и заполни:

   ```env
   ds_token=токен_из_Discord_Developer_Portal
   GUILD_ID=ID_твоего_сервера
   ```

   Логотип `img/icon.jpg` отображается в панелях, профиле и личных уведомлениях. Discord не позволяет обычному боту показывать локальный логотип или ссылочную кнопку в его статусе активности; активность остаётся текстовой.

   `GUILD_ID` нужен для быстрой регистрации slash-команд. Если его оставить пустым, Discord зарегистрирует команды глобально; они могут появиться не сразу.
7. Запусти `start.bat` и оставь это окно открытым. В Discord появятся `/setup`, `/panel`, `/ticket`, `/tickets`, `/stats`, `/profile`, `/close`, `/povish_send`, `/povish_set_date` и `/help`.
8. Выполни `/setup`. Это админ-панель для текста панели, каналов, ролей и статуса набора. Через **Открыть / закрыть набор** можно временно остановить подачу; опубликованная панель обновится сразу. При закрытом наборе кнопка объясняет, что заявки сейчас не принимаются. Категория заявок совпадает с категорией выбранного канала панели. После настройки нажми **Опубликовать панель**.

Чтобы бот оставался онлайн круглосуточно, запускай `start.bat` на компьютере, который не выключается, или перенеси папку на постоянно работающий VPS/сервер. После остановки процесса бот отключается; при повторном запуске настройки и заявки сохраняются в `data/rivalbot.sqlite3`.

## Команды

- `/setup` — меню настройки; доступно пользователям с правом управления сервером.
- `/panel [channel]` — опубликовать панель в выбранном или текущем текстовом канале.
- `/ticket` — показать сведения о заявке в текущей ветке.
- `/tickets` — вывести список открытых заявок (для поддержки).
- `/stats [member]` — приватная статистика выбранного участника за последние 7 дней; чужую статистику видят поддержка и администраторы.
- `/profile` — приватный профиль вызывающего: роли и статус в RIval, история принятия, стажировка и доступная боту статистика за неделю. Работает на сервере и в личных сообщениях с ботом.
- `/close` — запросить закрытие заявки; автор оценивает поддержку от 1 до 5 звёзд.
- `/help` — справка.
- `/povish_send` — опубликовать инструкцию по повышению (для админ-ролей).
- `/povish_set_date` — вручную указать дату получения Trainee для уже существующего стажёра.

В «Панели поддержки» после «Позвать на обзвон» приглашение публикуется внутри самой ветки тикета. Поддержка отмечает «Обзвон проведён», и только после этого становится доступна кнопка «Принять». При принятии бот выдаёт участнику роли Trainee и Clan, сохраняет дату стажировки в SQLite и отправляет одно уведомление с упоминанием админ-ролей в настроенный канал логов. ID роли Clan настраивается через `clan_role_id`.

В форме ответов показываются моноширинными блоками. Стафф не может взять заявку, которую подал сам. Принятый участник сохраняется в журнале SQLite; если у него есть роль Clan и запись о принятии, повторная подача блокируется. `/stats` и `/profile` показывают, кто и когда принял участника. При выдаче или снятии роли Clan бот пишет участнику в ЛС; состояние роли синхронизируется при запуске, чтобы рестарт не создавал ложных уведомлений. Всякая приватная реплика взаимодействия исчезает через минуту. Статус бота — «в самом крутом клане Rival Clan»; ссылка приглашения доступна кнопками в профиле, ЛС и панели заявок.

Участник с ролью `1503725660231700620` может открыть форму. Поддержка настраивается через `/setup` (по умолчанию `1558523889687199905`). Категория по умолчанию — `1558846469904146513`, канал логов — `1558844108171382945`.

Discord не размещает ветки непосредственно в категории. Бот создаёт каждую заявку отдельной **приватной веткой прямо под каналом, где опубликована панель**. Категория ветки автоматически совпадает с категорией канала панели; отдельный родительский канал больше не создаётся. Автор добавляется только в свою ветку; роли поддержки и администраторы добавляются в открытые ветки автоматически.

Для приватных веток бот дополнительно добавляет каждого текущего участника с ролью поддержки и каждого администратора непосредственно в ветку. При запуске он повторно синхронизирует доступ к уже открытым заявкам, поэтому старые ветки восстанавливаются после перезапуска. Если модератор удалит ветку, запись тикета удаляется из SQLite через событие Discord; при следующем запуске бот также очищает записи удалённых веток.

Для системы повышений включи в Developer Portal → Bot → Privileged Gateway Intents намерение **Server Members Intent**. Бот сохраняет дату начала стажировки и дату допуска в SQLite, поэтому перезапуск не сбрасывает неделю: проверка сравнивает сохранённую дату с текущей. Discord не отдаёт историю выдачи роли, поэтому для стажёров, которые получили Trainee до запуска бота, один раз используй `/povish_set_date` с реальной датой. Статистика сообщений и голосовых каналов начинает собираться после запуска бота; текст сообщений не сохраняется.

Если бот уже добавлен, открой **Настройки сервера → Роли → роль бота**, включи `Administrator` и сохрани изменения. Если использованные ID не относятся к этому серверу, выбери правильные значения в `/setup` перед тестовой заявкой.
